# Calculadora de Média em Java ☕

Projeto básico desenvolvido em Java para praticar entrada de dados, variáveis, operações matemáticas e estruturas condicionais.

## 📌 Funcionalidades

- Recebe o nome do aluno
- Recebe duas notas
- Calcula a média
- Informa se o aluno foi aprovado ou reprovado

## 🛠️ Tecnologias

- Java 21
- Scanner

## ▶️ Como executar

Compile o arquivo:

```bash
javac src/Main.java
```

Depois execute:

```bash
java -cp src Main
```
